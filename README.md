# 🍻 Adega Express - Catálogo Digital B2B

Um catálogo digital moderno, rápido e focado em conversão para adegas, distribuidoras de bebidas e serviços de tele-entrega. O projeto apresenta uma interface "Dark Mode" premium, ideal para o nicho de bebidas, e conta com integração direta para fechamento de pedidos via WhatsApp, facilitando a operação de negócios locais.

## 🚀 Funcionalidades

*   **Integração Direta com WhatsApp:** Os produtos clicados geram automaticamente uma mensagem formatada com o nome do item e o valor, enviando o cliente direto para o WhatsApp do lojista.
*   **Segurança de Contato:** O número de telefone e a string de exibição são ofuscados no código (Base64) para evitar raspagem de dados (scrapers).
*   **Mobile-First e Full-Screen:** O layout foi projetado para ocupar 100% da tela em dispositivos móveis, garantindo uma experiência de imersão semelhante a um aplicativo nativo.
*   **Aviso de Maioridade Legal:** Banner fixo e destacado no topo em conformidade com as regras de venda de bebidas alcoólicas.
*   **Categorização Estratégica:** Produtos divididos visualmente em seções de alta conversão (Combos Express, Cervejas Geladas, Destilados e Extras como gelo e carvão).
*   **Tags de Destaque:** Badges visuais (ex: "🔥 PROMOÇÃO", "🧊 TRINCANDO") para atrair a atenção do usuário para itens específicos.

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica e acessível.
*   **CSS3:** Estilização com Flexbox/Grid, variáveis de cor, transições suaves, efeitos de vidro (backdrop-filter) e design responsivo avançado.
*   **Vanilla JavaScript:** Lógica de renderização de listas de produtos, decodificação de strings e montagem dinâmica de URLs para a API do WhatsApp, sem necessidade de frameworks pesados.
